# SQLPilot — DBA 智能助手（v0.1）

桌面端数据库 AI Agent，支持 Oracle 11g/19c、OceanBase 4.x（MySQL / Oracle 租户）、MySQL。
大模型可配置多家厂商（厂商/型号直接选择，含思考级别），全部数据留在本机。

## 核心概念

- **功能模块**：最左侧一级导航切换——「AI 助手」（对话 / SSH 终端 / 会话管理）、「数据库」（数据库控制台，独立模块）、「云管平台」（OceanBase 云平台 OCP 的集群/租户/主机/告警/任务）、「文本编辑」（Notepad++ 式多标签编辑器，大文件秒开；选中文本可就地让 AI 针对这段内容问答）、「脱敏工具」（AWR 本地脱敏）与「巡检报告」（规划中，基于模板生成、与 AI 无关）；导航底部是全局工具（主题切换 / 设置浮窗）
- **文本编辑**：左侧「✎ 文本编辑」——多标签（标签栏位于编辑区上方，不横跨文件夹树；该模块不显示应用顶栏）、28 种语言高亮、正则查找替换（含文件夹内查找）、UTF-8/GBK/UTF-16 编码转换、CRLF/LF/CR 换行转换、列块选择、书签、括号匹配、自动换行、中文输入法。超过 24MB 的文件走"字节行索引 + 按需取行"的只读窗口模式，150MB 日志打开即可滚动；需要编辑时点横幅「载入完整内容以编辑」。双击 .sql/.log 等文件或命令行传路径可直接用本应用打开（已运行则复用窗口）。细节见 `文本编辑器说明.md`
- **文件脱敏工具**：左侧「脱敏工具」入口，先选择文件类型（当前开放 Oracle AWR，普通日志预留）再选择/拖入文件；内置规则面向 AWR 表格语义解析，覆盖 HTML 表格列 / `headers` 属性、文本列式报表、RAC 汇总、DB / PDB / DBID / 实例 / 主机 / 服务名 / Schema / OS 用户 / IP / ASM 磁盘组 / JDBC 与 TNS 组件，并避免数据库版本号、说明文字句号、SQL 别名等误报；同一敏感值在同一次处理中稳定映射为 `ip-tuoming1`、`db-tuoming1`、`host-tuoming1` 这类别名代称。前后对比视图左右显示原文与脱敏后文本，行号对齐并红 / 绿高亮；“映射备注”列出 `原始值 → 代称` 与命中次数，悬停高亮块也能看到前后备注；支持自定义正则、复制、另存，原始文件不会被修改
- **本机资源监控**：侧边栏底部常驻——CPU / 内存趋势 sparkline（3s 采样）与各盘占用条形，"−"收起为单行（品牌 · CPU%/内存% · DPAPI 状态）
- **项目**：选择一个文件夹注册为项目，是会话的工作单元（文件产出、连接关联都以项目为单位）
- **会话**：必须挂在一个项目下发起（点项目名或"＋"选择项目）；权限模式、模型、思考级别均为**会话级**设置，互不影响
- **数据库连接**：可选关联到某个项目（编辑连接时下拉选择）；不关联则为全局连接，所有会话可用
- **权限五档**：计划（agent 也会对复杂任务自动进入）→ 只读 → 确认执行 → 会话放开 → 完全放开
- **技能（Skills）**：Markdown 指令（含名称/描述），新建或导入 .md；启用后模型在任务匹配时自动 read_skill 并遵循执行。**随包内置 5 个基础技能**（SQL 性能诊断 / 变更评审 / 数据库巡检 / 数据导出与脱敏 / 建表与索引设计），首启播种到 `userData/skills`，可改可删，删了不会被重新写回
- **产物侧栏（结果预览）**：AI 助手右侧的结果预览栏——对话里每个工具产出的结果都会自动收进「产物」，按类型用不同渲染器展示：**结果集 / 表结构 / CSV → 可排序表格**（粘进 Excel、导出 CSV）、**DDL / SQL / 命令输出 → 带行号代码**（复制）、**Markdown → 排版后的报告**、**图片 → 直接预览**（可切原始大小）、**文件 → 路径与打开动作**。对话里每条产出的消息附一张「产物（N）」卡，点胶囊直达；顶栏「▦ 产物」或 **Ctrl+Shift+A** 开关右侧栏，面板宽度可拖拽并记忆。`db_query` 对模型只回前 30 行，**完整结果集落盘在 `userData/artifacts/`**（单份 ≤5 万行 / 24MB，7 天或 80 份后淘汰），面板打开时按 id 取全量——上下文不被结果集吃掉，DBA 又能看到全部行
- **项目指令（SQLPILOT.md）**：项目根放 `SQLPILOT.md`（无则回退 `AGENTS.md`），内容注入系统提示词且**优先级高于内置默认规则**——写"trade_db 是生产库、XX 表千万级禁全表扫、备份窗口凌晨 2-4 点"这类约定，该项目下的会话自动遵守
- **跨会话记忆**：agent 用 memory_append 工具把值得长期保留的事实追加到 `userData/memory/`，三个维度——**全局** MEMORY.md（跨项目通用）、**按连接** conn/<连接名>.md（挂在连接行下）、**按项目** project/<项目名>.md（仅绑定该项目的会话注入）；条目带日期、注入时截尾限长，与实际探测不符时以探测为准并更正
- **会话归档**：侧边栏会话行的归档按钮（▤）或输入框"归档对话"= 把对话总结（LLM 生成，失败回退本地抽取）写入 `userData/memory/archive/<项目名>.md` 后移除/清空会话——内容不丢弃，该项目后续会话的提示词自动带上归档总结作为任务背景
- **上下文摘要**：会话超长（条数 >200 或估算 tokens 超模型窗口 70%）时不再硬截断——被截掉的早期对话压缩成抽取式摘要（用户诉求 / 已确认结构的表 / 已执行的写操作 / 关键结论）随会话持久化并注入提示词，长巡检任务不会"失忆"后重复探索
- **子代理（agent_spawn）**：主代理可派生子代理执行独立子任务——子代理拥有**独立上下文**（看不到主会话历史），完成时只回传最终报告，中间工具结果不占用主会话上下文。内置两类：**explore**（只读探索/采集，工具面仅限只读+记忆，任何权限模式下都不能写）与 **general**（继承本会话权限，委托独立子任务）。同一批多个 agent_spawn **并行执行**（上限 3），多连接巡检/大 schema 扫描/日志排查一次扇出；权限钳制"子 ≤ 父"、写确认弹窗标注来源（"子代理 explore 请求…"）、父会话停止级联中止子代理、写审计打 `[sub:xxx]` 标；子代理无规划工具、不能再派生子代理。**后台执行**：长耗时采集传 `run_in_background`（前台超 2 分钟也自动转后台），立即返回任务 id 继续干别的，完成后系统通知送达下一回合（含摘要与报告文件），`task_output`（可阻塞等待）/`task_stop` 收割；**过程审计落盘**：每次子代理运行的完整过程（每步 SQL 全文/参数/结果/耗时）记入 `userData/subagent-runs/<id>.jsonl`，工具卡片"🔍 查看完整过程"可回看，报告另存 `项目/output/subagent-runs/<id>.md`；**LLM 流空闲看门狗**：SSE 连续 3 分钟无数据判定死流提前中断（VPN 断连不再干等总超时）
- **环境事实注入**：连接的数据库版本自动探测（成功缓存 30 分钟/失败 5 分钟，探测超时不阻塞对话）标注在连接行，方言规则按实际版本判断（Oracle 11g 用 ROWNUM、12c+ 可用 FETCH FIRST）；当前日期/时区注入提示词末尾，"昨天 / 近 7 天 / 本月"类相对时间有计算锚点（精确时刻仍建议用 SYSDATE/NOW() 核实）
- **数据库控制台**（左侧「数据库」一级模块，独立于 AI 助手）：Navicat 式布局——左侧连接/schema/表对象树（连接行常驻 ＋ 新建查询 / ℹ 数据库信息 / ⟳ 强刷；顶部 ＋ 新建连接，空态也能直接建连，不必回侧栏），右侧统一标签页：**查询窗口**（CodeMirror 高亮，Ctrl+Enter 执行，选中可单独执行；Oracle 工具栏 ✓ 提交 / ↩ 回滚；**⬇ 导出**查询结果为 CSV——可勾选要导出的列，重新执行查询取全量、上限 10 万行，UTF-8 带 BOM、Excel 双击直接打开）、**表数据页**（分页、点列头排序、WHERE 过滤、复制 TSV、网格编辑）、**结构/DDL 页**、**数据库信息页**（版本/状态/字符集/会话/存储，Oracle·MySQL·OB 各自适配；页首是 **KPI 磁贴**（实例/租户状态、归档模式、表空间使用率、连接数、锁等待、合并状态、缓冲池命中率、平均 QPS），正文按**主题块**组织——**每个块里图与它的明细同框**（表空间总体使用环 + 使用率 TOP 8 条形 + 表空间明细表；会话环 + 会话明细；SGA 组成堆叠 + 内存明细；对象/副本/Tablet 分布环 + 对应列表；库容量条形 + 容量表；活跃会话环 + 会话列表），不再把图集中堆在页面顶部；纯 SVG 绘制、日/夜主题自适应、数值越线（≥80% 黄、≥90% 红）自动变色；无明细可配的概况图（连接状态/缓冲池命中率）单独成卡片，采集诊断固定放页尾；Oracle 含**活跃会话**交互表——列集按当前库 GV$SESSION 真实结构动态获取、可勾选、可刷新）。**切换一级模块（去对话/文本编辑）再回来，查询标签页、结果集与未提交事务全部保留**（v-show 保活，只有标签栏 ✕ 关闭控制台才销毁）；导出进审计日志。从侧栏连接行点击同样直接进入本模块并定位该连接；**AI 助手会话切换时底部 SSH 终端面板自动隐藏**（隐藏不销毁——SSH 连接与终端回滚缓冲全部保留，回到该会话重开即恢复隐藏前的样子；终端面板的 ✕ 也是隐藏语义，关闭单个终端用 tab 上的 ✕）
- **结果网格编辑（DBeaver 式）**：表数据页**双击单元格**直接改值（Enter/点 ✓ 暂存，Esc 取消，∅ 设 NULL），暂存的修改高亮显示，点"💾 保存修改"批量执行 UPDATE——值全部绑定变量、按行标识（Oracle 用 ROWID，MySQL/OB 用主键）定位，改过的行被他人先改/删会报冲突。Oracle 保存后事务不提交，用状态条 ✓ 提交 / ↩ 回滚（与查询窗口一致，关标签页即回滚）；MySQL/OB 整批一个事务、有冲突全部回滚。视图（无行标识）、虚拟列/生成列自动只读，每处修改进审计日志
- **元数据缓存**：schema/表清单、表结构等元数据持久化缓存（`userData/meta-cache.json`），重启后对象树秒开、agent 循环内反复探索不再打库；⟳ 按钮强制重读，**应用内**执行 DDL（agent 或查询窗口）自动失效。注意：在应用**外**做的 DDL 需手动点 ⟳ 才能看到（DBeaver 同款约定）
- **事务语义按数据库特性**：Oracle 连接**不自动提交**——查询窗口/网格编辑的 DML 执行后事务保持打开，用工具栏 ✓ 提交 / ↩ 回滚（或直接执行 COMMIT/ROLLBACK）；DDL 在 Oracle 内部隐式提交（数据库自身行为）；MySQL/OB 为原生 autocommit，执行即生效
- **每个查询窗口 = 独立数据库会话**：窗口之间的未提交事务互相隔离（看不到、也不会被别窗口的 COMMIT 误提交），与 Navicat 行为一致；关闭窗口即断开该会话，未提交事务由数据库回滚
- **计划模式**：agent 对涉及写操作/多步骤的任务自动调用 enter_plan_mode 进入规划，输出结构化计划（目标/步骤/SQL/风险/回滚），点"批准并执行"后切换到确认执行模式开工；也可手动强制

```bash
npm install    # 首次
npm run dev    # 构建并启动（开发）
# 之后日常启动：
npm run build && npm start
```

## 首次使用四步

1. **建项目**：左侧"项目"区 ＋ → 选择文件夹 → 命名（会话必须挂项目）
2. **加连接**：左侧"数据库连接"区 ＋ → 填主机/端口/账号 → 测试连接 → 保存（可选关联到项目）
3. **配模型**：左下角"⚙ 设置"浮窗 → 选厂商（DeepSeek/GLM/千问/Kimi/OpenAI/Claude/**WorkBuddy 本地桥**）→ 选型号 → 填 API Key（**选 WorkBuddy 时不用填**，令牌由本机桥自动注入）
4. **开会话**：点击项目名即在该项目下新建会话；思考级别在输入框左下角切换

### 用 WorkBuddy 的模型额度（内置桥，零安装）

设置 → 添加提供商 → 厂商选「**WorkBuddy（本地桥）**」→ 点「启动」→「拉取模型」选型号 →「测试模型」→ 添加。**API Key 可以留空**。

- 桥（MIT 的 workbuddy-to-dsh）**随 SQLPilot 一起分发**，不用装 DeepSeek Harness、也不用装 Node。
- 端口：桥监听 `127.0.0.1:8790`，被占用会自动顺延（SQLPilot 内部按实际端口转发，不用改配置）；登录控制台 `8792` 只在点「登录 WorkBuddy」时临时启动。
- 令牌：由 SQLPilot 生成并用 Windows DPAPI 存在本机，不经过渲染层，也不写进配置文件。
- 前提：WorkBuddy 桌面端已登录（凭据是它运行时解封的，客户端里没有可复制的明文 Key）。
- 为什么不做直连：WorkBuddy 的 token 是 AES-GCM 信封、上游 `copilot.tencent.com` 还要 HMAC 签名，复刻等于每月跟着上游改，也属于绕开它的凭据保护——桥只用官方授权流程做协议翻译。

> 桥的日志在 `%APPDATA%\sqlpilot\wb-bridge.log`；它调用的是你自己账号的额度。WorkBuddy 在限制非官方客户端，这类通道随时可能失效，正式工作建议留一个官方 API 的提供商兜底。

19c 连接走纯协议免客户端；**11g 必须** Instant Client：

2. 解压到如 `D:\instantclient_19_28`
3. 设置 → 通用 → 填入目录并保存（或在单个连接里覆盖）

## 权限模式（顶栏）

| 模式 | 行为 |
|---|---|
| 🔒 只读 | 仅 SELECT/EXPLAIN/SHOW 等，写语句直接拦截 |
| 确认执行 | 写操作弹窗确认（仅此次/本会话/拒绝） |
| 🟡 会话放开 | 普通 DML 写确认一次后本会话自动；DDL 与高危（DROP/TRUNCATE 等）仍逐次确认 |
| 🔴 完全放开 | 全部自动执行（红色状态提醒） |

双保险：只读账号的连接即使放开权限也执行不了写操作。所有 SQL 均记录审计日志（设置页可查）。"本会话均允许"的放行范围按**工具+操作类别+目标**隔离：批准写文件不会顺带放开删文件，批准 DML 不会顺带放开 DDL。

**审计日志（v2，结构化可查）**：`userData/audit.log`（JSONL，超 4MB 轮转）每条记录带结构化字段——`actor`（发起者：agent 主代理 / sub:* 子代理 / human 工作台人工操作 / app 应用）、`sessionId`、`runId`（子代理运行，关联 `subagent-runs/` 完整过程）、`conn`、`tool`、`target`（schema.表 / 文件路径 / 服务器）、`sql`（全文）、`rows`、`ms`、`mode`、`approved`、`error`；字段规范见 `src/main/audit.ts` 头注释。设置浮窗的审计查看器支持按**类型/来源/连接/时间范围/只看失败/全文搜索**组合筛选、分页加载、点行展开完整 SQL 与错误明细——"今天这个库上谁执行了什么写操作"、"子代理都干了什么"一类问题直接可查。

- 数据文件位置：`%APPDATA%/sqlpilot/`（config.json、secrets.json、audit.log、sessions.json；旧版 DBAgent 数据首次启动自动迁移）
  - 数据库密码与大模型 API Key 均经 Windows DPAPI 加密存储，config.json 不落明文
- 对话历史持久化在 sessions.json，重启自动恢复（思考过程也恢复，默认折叠）；"归档对话"会把内容总结进项目归档后清空本会话，单会话历史超过 **200 条或估算 tokens 超模型窗口 70%** 时自动从最近的用户消息边界截断，被截内容压缩为抽取式摘要随会话保存（见"上下文摘要"）

- **会话上下文占用**：输入框左下上下文徽标实时显示"估算 tokens / 模型窗口 · 百分比"（>60% 黄、>80% 红）；悬停看明细：系统提示词+历史估算、最近一次请求的**真实计量**（输入/输出 tokens、**缓存命中与命中率**——厂商返回时）。窗口大小取厂商预设（如 GLM-Flash 1M、Claude 200K），提供商表单可覆盖

## 云管平台（OceanBase OCP）

左侧「☁ 云管平台」是独立模块：**不嵌 iframe**（OCP 自带 `X-Frame-Options: DENY`），而是由 SQLPilot 直接调用 OCP 的 REST 接口，用自己的界面展示。二级导航按厂商分组（当前只有 OceanBase，MySQL / Oracle 云管理为后续扩展位）。

- **接入**：底部「管理」填写 OCP 地址（可带 context path）、用户名、密码，**保存前会先验证一次登录**；密码经 Windows DPAPI 加密只存本机（`secrets.json`，键 `cloud:<id>`），不写进配置文件、不下发渲染层；内网自签证书可勾选「跳过 HTTPS 证书校验」。支持多套 OCP 并存，左下角切换
- **总览**：集群/租户/主机/告警/CPU 分配 KPI，集群容量卡片（CPU · 内存 · 数据盘水位，分配率接近 100% 属正常，只有数据盘按 90% 标红），活跃告警与最近任务两栏；页面 60 秒静默刷新（仅总览页）
- **集群**：列表（状态/版本/节点/租户/容量/告警）→ 详情（Zone、OBServer 进程与主机状态、租户、安装与端口等属性、启动参数）
- **租户**：跨集群总览，可按集群/模式筛选与搜索；点开右侧抽屉看副本分布、每个 Zone 的资源池与 Unit 落点（IP:port）
- **主机**：Agent 状态、机型、区域/IDC、操作系统、承载服务（OBServer / OBProxy）与 SSH 端口，可按状态筛选
- **告警**（对齐 OCP 告警中心）：**告警事件**分活跃 / 历史两个子 tab，顶部有分级统计卡与近 24 小时趋势（历史告警按小时分桶，可看每小时的严重/警告/注意构成），支持应用 / 对象类型 / 等级 / 关键词 / 时间窗筛选（均为 OCP 服务端过滤，`alarmType`/`appType` 实测生效）、列排序与 CSV 导出；详情抽屉给对象跳转（主机 / 租户 / 集群）、关联指标、阈值与实测值、同规则近 7 天告警次数、全量标签（自动隐藏 `en_us`/`zh_tw` 重复项）。**告警规则**只读页：规则清单（294 条实测）、检测表达式、评估间隔、持续与恢复超时、生效对象、告警文本模板；规则的新建 / 启停 / 改阈值属写操作，未开放
- **任务**：状态胶囊带计数（全部 / 已完成 / 执行中 / 失败，执行中合并 RUNNING+PENDING）、集群 / 发起者 / 对象类型 / 触发方式 / 时间筛选（服务端只认 status/name/clusterId/tenantId，其余由主进程在候选集内过滤并标注扫描范围）、耗时排序、执行进度条、CSV 导出，有任务在跑时 20 秒自动刷新；点行开详情抽屉：执行器与集群/租户、进度汇总、**子任务甘特时间轴**（按耗时占比、每步 start→end、runTime、节点类型、上下游依赖）
- 顶栏「↗ 打开 OCP」可跳系统浏览器打开原生控制台
- **资源监控**：集群 / 租户 / 主机三个维度，时间范围 30 分钟～24 小时，指标按需勾选（QPS、TPS、活跃会话、CPU/内存、MemStore、SQL 平均耗时、缓存命中率、主机负载与 IO），纯 SVG 折线图、可悬停看具体时刻，页面 30 秒自动刷新
- **运维动作**（集群详情右上）：重启 / 停止 / 启动 / 立即合并 / 删除，均二次确认后提交给 OCP，返回任务号可到「任务」页看进度
- **集群创建**（集群页「创建集群」）：三步向导——基本信息（软件包下拉取自 OCP 软件包列表，`/api/v2/software-packages`，仅 OB 安装包）、Zone 与主机（只有未承载 OB 集群的空闲主机可选）、预检查；预检查自动提交 `createPreCheck` 并代为轮询异步检查项（`/api/v2/precheck/{checkId}/item/result`），通过项/失败项（含失败原因与建议）一次列全后带 `checkId` 提交，进度到「任务」页看
- **参数查看**：集群详情「参数」页签展示 OB 启动参数（按 参数 × 租户 × 服务器 拍平），只读
- **租户创建 / 删除**：集群详情「＋ 创建租户」填名称、MySQL/Oracle 模式、字符集、root 初始密码（提交前 RSA 加密）、副本 Zone、Unit 规格与数量、白名单；租户抽屉右上「删除」走 OCP 删除任务
- **租户管理**（租户抽屉，对齐 OCP 租户详情页）：顶部「改密 / 白名单 / 锁定·解锁」（改密按 OCP 惯例 RSA 加密后提交）；「概览」页签编辑副本（Unit 规格 / 数量 / 副本类型，走 `modifyReplica` 整份提交）、新增副本（`addReplica`）、删除副本（`deleteReplica`）；「参数」页签查看并可行内修改（`PUT /parameters`）；「会话」页签列表、过滤、单个或批量结束（`sessions/close {sessionIds}`）。涉及集群创建类的动作均返回任务号，可到「任务」页看进度；sys / meta 租户的锁写等危险操作由 OCP 侧保护并回显原因
- **鉴权实现**（逆向自 OCP 4.x 前端）：`GET /api/v2/sensitiveDataKey` 取公钥 → `POST /api/v2/iam/login` 提交 **RSA/PKCS#1 v1.5 加密后的密码** → 拿 `SESSION` Cookie；会话失效自动重登一次，首屏并发请求共享同一次登录

## 文本编辑（Notepad++ 式）

左侧「✎ 文本编辑」是独立于 AI 助手会话的文本编辑器，能力对照与取舍见 [`文本编辑器说明.md`](文本编辑器说明.md)。

- **大文件**：≤ 24MB 整篇载入、可编辑；> 24MB 走只读窗口模式（原始字节 + 行起始字节偏移索引，按可视区取行），150MB / 162 万行日志打开即可滚动、可查找、可跳行；横幅「载入完整内容以编辑」可切换到可编辑模式
- **编码**：BOM/UTF-8 严格校验/GBK 回退自动探测；保存沿用文件原编码，也可在「编码」菜单转换或用指定编码重新打开
- **查找**：普通/正则/全字/大小写/循环；替换支持 `$1`/`$&`；「在文件夹中查找」递归检索文本文件并列出结果，点击跳转
- **Markdown**：标签栏右侧「源码 / 即时 / 预览 / 分屏」手动切换；「即时」是 Typora 式所见即所得（整篇渲染，点到哪块哪块变源码，代码块直接编辑代码），回车新段、列表续写、Esc 提交；工具条 + 快捷键（Ctrl+B/I/K、Ctrl+1–6、Ctrl+Shift+M）覆盖粗体、标题、列表、任务、引用、链接、代码块、表格等；渲染先转义再解析，不执行原文 HTML
- **文件夹树**：「文件 → 打开文件夹…」或把文件夹拖进窗口，左侧出现 Folder as Workspace 式目录树（按需展开、点文件即开、自动定位当前文件、记住展开状态与宽度）；点标题可在多个已打开的文件夹之间切换（各自记住展开状态，可移除）
- **打开方式**：文件对话框（「全部文件」，任意扩展名）／把文件或文件夹直接拖进窗口／`SQLPilot.exe D://path//a.sql`（或目录）／关联后双击；应用已在运行时复用当前窗口
- **选中文本问 AI**：菜单栏最右侧固定一个「✦」图标——在源码编辑区选中一段（代码 / SQL / 日志 / 普通文本都行）它就**高亮并亮起小圆点**，点开是针对这段内容的浮窗（标题写明「文件名 · 语言 · 第几行 · 多少字符」，原文可折叠查看）；没选中时点它是打开历史会话。浮窗**可拖动、八向缩放、双击标题恢复默认**，位置与大小本机记忆；「历史」里按时间列出所有问答（每条存选区 + 消息，最多 60 条），点一条即回到那次对话并可继续追问。回答流式输出，可停止、Esc 关闭；**只读选中内容，不会改动文件**。换选一段再点图标即开新会话（上一段问答清空，历史里仍可找回）。上下文上限 12000 字符 / 800 行，超出截断并注明；**工作区文件树里每个文件行 hover 有「✦」**，点它打开「选择文件」弹层（含搜索、全选），**可多选**——这个文件先勾上，再勾别的文件，确认后一起读成上下文（`===== 文件：x =====` 分隔，模型回答跨文件问题时会点明文件名）；浮窗顶栏的「文件」按钮可随时换 / 加文件，历史里的「＋ 选择文件」是没选中文本时的入口。只读、不打开标签，单文件 > 4MB 会提示，多文件总预算 24000 字符（超出按顺序截断并提示）。
- **技能（回答规范）**：三个就地助手（云管 AI、Oracle AI、编辑器 AI）的浮窗顶栏都有「技能」按钮——勾上「设置 → 技能」里已启用的技能，它的 `SKILL.md` 正文会作为**回答规范**随问题一起发给模型（按你的巡检步骤、判断阈值与输出格式作答）；不勾则完全不受影响。这一路**只注入正文、不执行技能里的工具**（不给 `read_skill`、不给 `sql_query`），技能引用的附属资源文件读不到，需要时会让模型说明缺哪份资料。最多同时带 4 个技能，单技能 4200 字符 / 合计 9000 字符封顶，技能选择是浮窗级设置、不写进历史会话
- **AI 回答的阅读与复用**：两端（文本编辑器 / 云管平台的 OCP·Oracle 助手）共用同一套回答气泡——每个用户问题与 AI 回答各自用圆角气泡围住、上下分明；回答按 Markdown 渲染（标题 / 列表 / 表格 / 代码块）。每条回答下方有「复制全文」（复制模型原始 Markdown），每个代码块右上角有「复制」（只复制这段代码，hover 才显示）
- **语言识别**：按扩展名识别 28 种语言；无扩展名或未知扩展名（如 `alert_xxx`、`sqldump`）按开头内容嗅探（SQL / 日志 / JSON / INI / Shell / Python），也可在「语言」菜单手动切换

## 隐私：发给大模型的内容与两项保护

对话时发送给模型厂商 API 的是：系统提示词 + 全部对话历史（含工具结果：查表数据最多 30 行预览、读到的文件/日志内容、命令输出等）+ 工具定义。系统提示词还包含环境事实（OS/数据库版本标签、当前日期）与你维护的本地指令内容（项目根 SQLPILOT.md/AGENTS.md、跨会话记忆、超长会话的历史摘要）。**密码与 API Key 永远不进对话内容**（Key 仅在 HTTPS 请求头做认证）。两项可选保护：

- **系统提示词脱敏**（设置 → 通用，默认开）：不发送连接的服务名/库名、SSH 服务器的地址与账号、项目本地路径等明细，模型按名称寻址，能力不受影响
- **发送前预览**（设置 → 通用，默认关）：开启后每次请求发出前弹窗展示**完整请求体**（就是实际发出去的 JSON），可逐次确认发送/取消；关闭功能即恢复直发

## 已知边界（M2 计划）

- 无内嵌终端（xterm.js + SSH 在 M2）
- 停止任务会在最近的检查点结束：LLM 流式输出立即中断，正在执行的数据库工具会等它跑完（最长 60 秒超时）后停止
